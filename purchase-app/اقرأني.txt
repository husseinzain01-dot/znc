نظام طلبات الشراء وسلسلة الموافقات
=====================================
برنامج مستقل يعمل على لابتوبك فقط، وقاعدة بياناته SQL Server.
لا يحتاج إنترنت أثناء العمل، ولا يظهر لأي جهاز آخر على الشبكة.


المتطلبات (مرة واحدة)
---------------------
1) Node.js — نسخة LTS من https://nodejs.org (تثبيت عادي: Next ثم Next).
2) SQL Server — أي نسخة (Express المجانية تكفي). إذا كان مثبتاً عندك لنظام آخر فاستخدمه نفسه.


إعداد SQL Server (مرة واحدة)
----------------------------
البرنامج يتصل بحساب SQL Server (اسم مستخدم وكلمة مرور)، لذلك تأكد من:

أ) تفعيل الدخول بحساب SQL:
   افتح SQL Server Management Studio ← كليك يمين على اسم الخادم ← Properties ← Security
   ← اختر "SQL Server and Windows Authentication mode" ← OK ثم أعد تشغيل خدمة SQL Server.

ب) تفعيل TCP/IP:
   افتح "SQL Server Configuration Manager" ← SQL Server Network Configuration
   ← Protocols for (اسم النسخة) ← فعّل TCP/IP ← أعد تشغيل خدمة SQL Server.
   ملاحظة لنسخة Express: شغّل أيضاً خدمة "SQL Server Browser"، أو ثبّت المنفذ 1433.

ج) إنشاء قاعدة البيانات والحساب:
   الأسهل: استخدم حساب sa (أو أي حساب بصلاحيات كاملة) والبرنامج ينشئ كل شيء تلقائياً.
   أو إذا أردت حساباً محدود الصلاحيات: افتح ملف schema.sql في SQL Server Management Studio،
   غيّر كلمة المرور ChangeMe_StrongPassword إلى كلمة مرور من عندك، ثم اضغط Execute.
   سينشئ قاعدة البيانات PurchaseRequestsDB وكل الجداول وحساب purchase_app.


التشغيل لأول مرة
----------------
1) شغّل الملف  start.bat  (دبل كليك). تبقى نافذة سوداء مفتوحة — هذا هو البرنامج.
2) يفتح المتصفح تلقائياً على  http://localhost:4810  وتظهر شاشة "إعدادات قاعدة البيانات":
      اسم الخادم       localhost
      اسم النسخة       اتركه فارغاً، أو اكتب SQLEXPRESS إذا كانت نسختك Express باسمها الافتراضي
      المنفذ           1433
      قاعدة البيانات   PurchaseRequestsDB
      المستخدم         sa  أو  purchase_app (إذا شغّلت schema.sql)
      كلمة المرور      كلمة مرور ذلك الحساب
   اضغط "اختبار الاتصال"، وإذا نجح اضغط "حفظ والاتصال".
   (تُحفظ الإعدادات على هذا الجهاز فقط في الملف data\config.json)
3) أدخل اسم الشركة وأنشئ حساب مدير النظام.
4) (اختياري) شغّل  create-desktop-shortcut.bat  لوضع اختصار على سطح المكتب.

تغيير إعدادات قاعدة البيانات لاحقاً: ادخل بحساب المدير ← "سلسلة الموافقات" ← أسفل الصفحة "اتصال قاعدة البيانات".
وإذا تعذر الاتصال عند التشغيل، تظهر شاشة الإعدادات تلقائياً لتصحيحها.


الاستخدام اليومي
----------------
• افتح البرنامج من اختصار سطح المكتب (أو start.bat).
• تبقى نافذة سوداء مفتوحة — هذا هو البرنامج نفسه. لا تغلقها أثناء العمل.
  عند الانتهاء أغلقها ليتوقف البرنامج.
• إذا أغلقت نافذة البرنامج بالخطأ افتح المتصفح على:  http://localhost:4810


الإعداد داخل البرنامج
---------------------
• الحساب الذي تنشئه أول مرة هو "مالك النظام" 👑 — وهو وحده يضبط سلسلة الموافقات وإعدادات
  قاعدة البيانات. لا يستطيع أي مستخدم آخر تغييرها، حتى لو كانت صلاحيته "مدير نظام".

1) "المستخدمون والأقسام": أضف كل من سيقدّم طلبات أو يعتمدها.
   - القسم (إلزامي): اختره من القائمة أو اكتب اسم قسم جديد ويُضاف تلقائياً.
     قسم المستخدم هو الذي يحدد سلسلة موافقات طلباته.
   - لحساب المشتريات: ضع علامة على "موظف مشتريات" (يصدر أوامر الشراء ويسجل الاستلام).
   - في أسفل الصفحة تستطيع إضافة وحذف الأقسام وفئات المشتريات.
2) "سلاسل الموافقات" (للمالك فقط): لكل قسم سلسلة موافقات خاصة به.
   - اضغط على القسم ثم "إنشاء سلسلة خاصة"، وحدد المراحل والمستخدم المعتمد لكل مرحلة، ثم احفظ.
   - القسم الذي ليس له سلسلة خاصة يستخدم "السلسلة العامة".
   - طلب أي مستخدم يمر تلقائياً بسلسلة قسمه، ولا يستطيع اختيار قسم آخر.
   - الحد الأدنى للمبلغ اختياري — اتركه 0 لتُطبَّق المرحلة على كل الطلبات.

   مثال: قسم الإنتاج ← الإدارة ← المالية
     • الإنتاج يرفع الطلب: يراه الإنتاج والإدارة فقط.
     • توافق الإدارة: يُرسل إلى المالية، ومن هنا تراه المالية.
     • كل معتمد لا يرى الطلب قبل أن يصل دوره.


دورة الطلب
----------
مسودة ← إرسال للموافقة ← موافقات المراحل بالترتيب ← معتمد ← إصدار أمر شراء ← استلام جزئي/كامل ← مغلق
• المعتمد لا يرى الطلب ولا يستطيع اعتماده إلا بعد وصوله إلى مرحلته، أي بعد موافقة المرحلة التي قبله.
  (هذا يشمل حساب مدير النظام: لا يرى طلبات الآخرين إلا عند وصولها لمرحلته أو بعد اعتمادها للشراء.)
• المعتمد يستطيع: الموافقة، أو إعادة الطلب للتعديل، أو الرفض (السبب إلزامي للإعادة والرفض).
• إذا أُعيد الطلب للتعديل ثم أُرسل من جديد يبدأ من المرحلة الأولى.
• السلسلة إجبارية على الكل بلا استثناء: لا تُتخطّى أي مرحلة، ولا يعتمد أحد طلبه بنفسه.
  إذا كان مقدم الطلب هو معتمد إحدى المراحل (مثلاً مدير القسم يطلب لنفسه) يعتمد مالك النظام تلك المرحلة بدلاً عنه.
• مقدم الطلب لا يستطيع اعتماد طلبه بنفسه (فصل المهام).
• كل إجراء يُسجّل في السجل الزمني للطلب باسم من قام به ووقته.
• كل القواعد تُطبّق داخل البرنامج نفسه، فلا يمكن تجاوزها من المتصفح.
• يمكن إرفاق عروض الأسعار والفواتير (حتى 8 ميغابايت للملف)، وتُحفظ داخل قاعدة البيانات.
• يمكن طباعة نموذج الطلب الرسمي مع جدول التواقيع، وتصدير القائمة إلى Excel.


النسخ الاحتياطي
---------------
• من البرنامج: "سلسلة الموافقات" ← "أخذ نسخة احتياطية الآن"
  (يُحفظ ملف .bak في مجلد النسخ الافتراضي لـ SQL Server، والمسار يظهر لك بعد الحفظ).
• أو من SQL Server Management Studio: كليك يمين على PurchaseRequestsDB ← Tasks ← Back Up.
• انسخ ملفات النسخ إلى فلاشة أو مكان آخر بين فترة وأخرى.


حل المشاكل
----------
• "تعذر الوصول إلى SQL Server": تأكد أن خدمة SQL Server تعمل، وأن TCP/IP مفعّل،
  وأن اسم الخادم والمنفذ صحيحان في شاشة إعدادات قاعدة البيانات.
• "رفض SQL Server تسجيل الدخول": كلمة المرور خطأ، أو الدخول بحساب SQL غير مفعّل (الخطوة أ).
• "Port 4810 is already in use": البرنامج يعمل أصلاً — افتح http://localhost:4810
  (أو أغلق النافذة السوداء القديمة وشغّل start.bat من جديد).
• نسي مستخدم كلمة مروره: يغيّرها له مدير النظام من "المستخدمون والأقسام".
• نسيت كلمة مرور مالك النظام: شغّل reset-owner-password.bat فيعطيك كلمة مرور مؤقتة، ثم غيّرها من زر 🔑.
