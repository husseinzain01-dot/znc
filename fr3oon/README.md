# Fr3oon

نظام مستقل لإدارة المحل يعمل على Windows بقاعدة بيانات Access خاصة به:

- **البيع السريع (POS)** بالباركود، نقداً وآجلاً وبالجملة، مع طباعة الفاتورة.
- **الإدخال:** فواتير البيع والشراء، وسندات القبض والصرف والمصروفات، والعملاء والموردون والأصناف والأسعار، مع التعديل والحذف.
- **التقارير:** المبيعات والمشتريات، وأرصدة العملاء والموردين وكشوف الحساب، والمخزون، والصندوق، والأرباح، وملاحظات البيانات.
- **المستخدمون والصلاحيات** محفوظة في قاعدة البيانات (كلمات المرور مُجزّأة بـ PBKDF2)، مع قوالب جاهزة (كاشير، بائع جملة، محاسب). البرنامج المساعد يتحقق من الصلاحيات في كل عملية حفظ.
- **الترخيص:** مفتاح تفعيل مرتبط برمز الجهاز وموقّع من الناشر (ECDSA P-256)، دون فترة تجربة.
- **النسخ الاحتياطي:** نسخة يومية تلقائية إلى مجلد يختاره المستخدم، مع الاستعادة.
- **التحديثات عبر الإنترنت:** من GitHub، ولا يُثبَّت إلا تحديث موقّع من الناشر، بعد نسخة احتياطية.
- **أجهزة إضافية** على الشبكة أو عبر VPN، تعمل على بيانات الجهاز الرئيسي.
- **فحص النظام والفحص الشامل** للتحقق من الحفظ والتقارير على الجهاز نفسه.

جميع نصوص الواجهة باللغة العربية الفصحى.

## كيف يعمل

```
اختصار سطح المكتب → Fr3oon.exe (NSIS، بلا نافذة)
  → launch.ps1: يشغّل server.ps1 مخفياً إن لم يكن يعمل، ويفتح Edge بنافذة تطبيق
server.ps1 (http://localhost:8770)
  ├─ يقدّم fr3oon.html (الواجهة كلها في ملف واحد)
  ├─ /api/state، /api/activate، /api/setup: الترخيص وإنشاء قاعدة البيانات
  ├─ /api/login: المستخدمون من جدول Users
  ├─ /api/data: الجداول بصيغة JSON مضغوطة (DAO GetRows)
  ├─ /api/write: كل عمليات الحفظ داخل معاملة واحدة بمحرّك DAO
  └─ النسخ الاحتياطي، الاستعادة، التحديثات، الفحوصات
```

- قاعدة البيانات: `C:\Fr3oon\Data\fr3oon.accdb` افتراضياً، تُنشأ بـ `DBEngine.CreateDatabase` وبنية الجداول في `$Schema` داخل `server.ps1`.
- إعدادات الجهاز والترخيص والسجل: `%APPDATA%\Fr3oon`.
- يحتاج Microsoft Access أو Microsoft Access Database Engine على الجهاز.

## البناء

```bash
npm install
node build.mjs              # release/fr3oon.html
bash installer/build.sh     # dist/Fr3oon-Setup-<version>.exe (يحتاج makensis وPlaywright)
```

رقم الإصدار في `server/server.ps1` (`$Version`).

## الترخيص والتحديثات (للناشر)

`vendor/Fr3oon-Keys.html` أداة تعمل دون إنترنت في Chrome أو Edge، وتحتاج ملف المفتاح الخاص `Fr3oon-private-key.json`.
**المفتاح الخاص لا يُرفع إلى أي مستودع أبداً.** إذا ضاع فلا يمكن إصدار مفاتيح أو تحديثات يقبلها البرنامج المثبّت.

- **مفتاح تفعيل:** يرسل العميل «رمز هذا الجهاز» من شاشة التفعيل، فتُصدر له مفتاحاً باسمه (دائماً أو حتى تاريخ).
- **نشر تحديث:**
  1. ارفع `$Version` في `server/server.ps1`، وابنِ ملف التثبيت.
  2. في المستودع العام `husseinzain01-dot/fr3oon-updates` أنشئ Release باسم `v<version>` وارفع إليه `Fr3oon-Setup-<version>.exe`.
  3. في الأداة اختر ملف التثبيت واكتب ما الجديد، ثم نزّل `latest.json` واستبدل به الملف الموجود في جذر المستودع.
  4. يجد البرنامج التحديث من «الإعدادات ← التحديثات»، ويتحقق من التوقيع ومن SHA-256 للملف قبل تثبيته بصمت (`/S /RELAUNCH`).

يمكن تغيير رابط ملف التحديثات لجهاز معيّن بالمفتاح `updateUrl` في `%APPDATA%\Fr3oon\config.json`.

## الاختبارات

```bash
KEEP_TMP=1 pwsh server/test/run-ops.ps1   # الترخيص وإنشاء القاعدة والمستخدمون وكل عمليات الحفظ والصلاحيات
                                          # والنسخ الاحتياطي والاستعادة والتحديثات وفحص النظام (يطبع مجلده المؤقت)
node test/fulltest.test.mjs <المجلد المؤقت>     # نصف الفحص الشامل الذي يجري في الواجهة
node test/data-export.test.mjs <المجلد المؤقت>  # بيانات الأجهزة الأخرى تعطي التقارير نفسها
```

الاختبارات تعمل دون Access عبر `server/test/FakeDao.ps1` (`LAWHA_FAKEDAO`)، وتستخدم مفتاح الاختبار
`server/test/test-vendor-key.json` الذي لا يقبله البرنامج إلا في وضع الاختبار.
