# لوحة المحل

برنامج يشتغل على نفس بيانات برنامج **حساباتي** (ملف `Units2026.accdb`)، وحساباتي يبقى يشتغل يمّه عادي:

- **بيع سريع (POS):** أزرار المواد حسب الصنف، بحث بالاسم أو الرمز أو الباركود، نقدي وآجل، حفظ (F9) وحفظ وطباعة وصل (F10).
- **إدخال:** قوائم بيع وشراء، وصولات قبض ودفع ومصاريف، زبائن، موردين، مواد وأسعار، ويه التعديل والمسح.
- **تقارير:** المبيعات، المشتريات، أرصدة الزبائن والموردين وكشوفات الحساب، المخزن، الصندوق، الأرباح، وملاحظات على البيانات.
- **دخول بنفس مستخدمين حساباتي وكلمات السر مالتهم، وصلاحيات لكل مستخدم:** المدير يسوي كلشي؛ الباقين يشوفون الشاشات ويسوون العمليات اللي يأشّرها المدير إلهم (بيع نقدي / آجل / جملة، تغيير السعر، تعديل ومسح القوائم، الشراء، الوصولات…)، ويه قوالب جاهزة (كاشير نقدي، كاشير نقدي وآجل، بائع جملة، محاسب). الافتراضي: بيع نقدي وطباعة بس. البرنامج المساعد يفحص نفس الصلاحيات بكل حفظ.
- **فحص النظام:** يجرّب كل عمليات الحفظ على الملف الحقيقي داخل معاملة ويلغيها، حتى تتأكد على نفس الجهاز إن كلشي يشتغل.

## التنصيب (Windows)

`dist/LawhatAlMahal-Setup-<version>.exe` (يطلع من `installer/build.sh`):

- ينصّب للمستخدم الحالي بدون صلاحية مدير، بـ `%LOCALAPPDATA%\Programs\LawhatAlMahal`.
- اختصار على سطح المكتب وبقائمة ابدأ، وإزالة من Apps & features.
- أول تشغيل يطلب ملف البيانات مرة وحدة؛ ينحفظ بـ `%APPDATA%\LawhatAlMahal\config.json` ويبقى حتى بعد التحديث أو إعادة التنصيب.
- يحتاج Microsoft Access أو Access Runtime على نفس الجهاز (الكتابة تصير بمحرك Access نفسه).

## شلون يشتغل

```
اختصار سطح المكتب → LawhatAlMahal.exe (NSIS، بدون نافذة)
  → launch.ps1: يشغّل server.ps1 مخفي إذا مو شغّال، ويفتح Edge بنافذة تطبيق
server.ps1 (http://localhost:8765، هذا الجهاز بس)
  ├─ يقدّم lawha.html (البرنامج كله بملف واحد)
  ├─ /api/file: يعطي المتصفح ملف البيانات، والمتصفح يقراه بـ mdb-reader
  ├─ /api/login: يفحص الاسم وكلمة السر من tblUsers مثل حساباتي
  └─ /api/write: يكتب بـ DAO (محرك Access) داخل transaction، ويسوي نسخة احتياطية قبل أول حفظ بكل يوم
```

- إذا انفتح `release/hisabati-reader.html` مباشرة (دبل كلك) يشتغل **قراءة بس** بدون server.
- الحقول تنكتب مثل ما يكتبها حساباتي (من كود VBA مالته)، والأرصدة والمخزن والصندوق بنفس معادلات استعلاماته.
- الأسماء تربط القوائم بالزبائن والمواد، فتغيير اسم زبون أو مادة يتغير بكل القوائم القديمة بنفس الحفظ.

## للمطوّر

```bash
npm install
npm run build                                     # release/hisabati-reader.html
node test/calc.test.mjs Units2026.accdb           # التقارير على ملف حقيقي
node server/test/export-tables.mjs Units2026.accdb tables.json
pwsh server/test/run-ops.ps1 -Tables tables.json -DbFile Units2026.accdb   # كل عمليات الحفظ (116 فحص)
installer/build.sh                                # dist/LawhatAlMahal-Setup-<version>.exe (يحتاج makensis)
```

| الملف | شنو بيه |
|---|---|
| `src/load.js` | يقرا جداول حساباتي ويحوّلها لأسماء إنكليزية (ما يقرا كلمات السر) |
| `src/calc.js` | كل التقارير، دوال بدون واجهة تنفحص بـ Node |
| `src/app.js` | الواجهة: الدخول، القائمة الجانبية، التقارير |
| `src/pos.js` | البيع السريع |
| `src/forms.js` | شاشات الإدخال والتعديل وطباعة الوصل |
| `src/settings.js` | الإعدادات وفحص النظام |
| `server/server.ps1` | المساعد المحلي (Windows PowerShell 5.1) |
| `server/test/FakeDao.ps1` | بديل لـ DAO للفحص بدون Access: يرفض أسماء الحقول الغلط والنصوص الطويلة والأنواع الغلط مثل Access |
| `installer/` | الأيقونة، المشغّل، وسكربتات NSIS |

- `LAWHA_FAKEDAO=tables.json` يشغّل `server.ps1` على نسخة بالذاكرة (بدون Access) للفحص.
- قراءة Access بمكتبة [mdb-reader](https://github.com/andipaetzold/mdb-reader)، وأجزاء التشفير مستبدلة بـ `src/stubs` لأن ملفات حساباتي مو محمية بكلمة سر.
