# لوحة المحل

برنامج يشتغل على نفس بيانات برنامج **حساباتي** (ملف `Units2026.accdb`):
- **يقرا ويطلّع التقارير:** المبيعات، المشتريات، أرصدة الزبائن والموردين وكشوفات الحساب، المخزن، الصندوق، الأرباح، وملاحظات على البيانات.
- **يكتب على نفس الملف:** قائمة بيع (نقدي وآجل) وطباعة وصل، قائمة شراء، وصل قبض، وصل دفع ومصاريف، زبائن، موردين، ومواد وأسعارها، ويه التعديل والمسح.
  كل شي ينحفظ بنفس الطريقة اللي يحفظ بيها حساباتي، فيطلع بحساباتي عادي.

يشتغل بطريقتين:

| الطريقة | شلون | شنو يسوي |
|---|---|---|
| **قراءة وكتابة** | `server/start.bat` على الحاسبة اللي عليها Access | يقرا ويكتب |
| **قراءة بس** | دبل كلك على `release/hisabati-reader.html` | تقارير بس، ما يغيّر شي |

## القراءة والكتابة (الحاسبة اللي عليها Access)

1. حط فولدر `server` (فيه `start.bat` و `server.ps1` و `lawha.html`) بأي مكان على الحاسبة.
2. دبل كلك على `start.bat`. أول مرة يسألك وين ملف `Units2026.accdb` ويتذكره.
3. ينفتح البرنامج بالمتصفح على `http://localhost:8765/`. اختار اسمك من **المستخدم** فوك.
4. خلّي نافذة PowerShell الصغيرة مفتوحة طول ما تشتغل؛ إذا سدّيتها يوكف الحفظ.

- قبل أول حفظ بكل يوم ينسوى نسخة احتياطية من الملف بفولدر `backups-lawha` يم ملف حساباتي (آخر 30 نسخة).
- كل حفظ ينسوى كله لو ما ينسوى شي (transaction)، فما تبقى قائمة نص.
- الحفظ يحتاج Microsoft Access أو Access Runtime على نفس الحاسبة، لأن الكتابة تصير بمحرك Access نفسه.
- يقبل طلبات من نفس الحاسبة بس (localhost).

## القراءة بس

- **ملف واحد:** `release/hisabati-reader.html`، ما يحتاج تنصيب ولا إنترنت ولا Access.
- **يشتغل على** Edge أو Chrome بالويندوز. التحديث التلقائي يحتاج Edge أو Chrome.

### خطوات القراءة بس

1. انسخ `release/hisabati-reader.html` لأي مكان (مثلاً سطح المكتب أو `D:\`).
2. دبل كلك عليه، ينفتح بالمتصفح.
3. دوس **فتح ملف البيانات** واختار `Units2026.accdb` (من فولدر حساباتي).
4. المرة الجاية دوس **فتح آخر ملف** أو **تحديث** بس. وإذا أشّرت على **تحديث تلقائي** يرجع يقرا الملف كل دقيقة.

### من جهاز ثاني (لابتوب)
البرنامج يقرا الملف من أي مكان يوصله الويندوز. حتى تشوف البيانات الحية من اللابتوب:
شارك فولدر حساباتي على شبكة المحل (كلك يمين على الفولدر ← Properties ← Sharing)،
وبعدين من اللابتوب افتح الملف من `\\اسم-الحاسبة\Units2026\Units2026.accdb`.

## الحسابات

نفس معادلات حساباتي (مأخوذة من استعلاماته):

| التقرير | المعادلة |
|---|---|
| رصيد الزبون | رصيد افتتاحي + مبيعات آجل − المدفوع مع القوائم الآجلة − التسديدات |
| رصيد المورد | رصيد افتتاحي + مشتريات آجل − التسديدات |
| المخزن | الرصيد الافتتاحي + المشتريات − المبيعات لكل وحدة، والقطع الزايدة تنحسب كراتين |
| الصندوق | مبيعات نقدي + المدفوع مع القوائم + التسديدات − مشتريات نقدي − المدفوعات |
| الربح | (سعر البيع − سعر الشراء المسجل ويه سطر البيع) × الكمية |

فرق واحد مقصود: إذا المادة وحدتها الكبيرة والصغيرة بنفس الاسم (مثل كارتون/كارتون)، حساباتي يحسب رصيدها مرتين، وهذا البرنامج يحسبه مرة وحدة.

## للمطوّر

```bash
npm install
npm run build                                   # يطلّع release/hisabati-reader.html
node test/calc.test.mjs path/to/Units2026.accdb # يفحص الحسابات على ملف حقيقي
```

- `src/load.js` يقرا الجداول ويحوّلها لأسماء إنكليزية.
- `src/calc.js` كل التقارير (دوال بدون واجهة، تنفحص بـ Node).
- `src/app.js` الواجهة، و`src/forms.js` شاشات الإدخال.
- `server/server.ps1` المساعد المحلي: يقدّم البرنامج والملف، ويكتب بـ DAO (محرك Access) داخل transaction.
  `LAWHA_MOCK=1` يشغّله بدون Access (يسجّل الكتابات بـ `mock-writes.log` بدل ما يحفظها) للتجربة.
- للتوزيع: انسخ `release/hisabati-reader.html` إلى `server/lawha.html` ويه `server.ps1` و `start.bat`.
- قراءة ملف Access بمكتبة [mdb-reader](https://github.com/andipaetzold/mdb-reader). أجزاء التشفير مستبدلة بـ `src/stubs` لأن ملفات حساباتي مو محمية بكلمة سر.
