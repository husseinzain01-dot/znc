نسخة GitHub Pages جاهزة - نظام متابعة الوجبات

طريقة الرفع:
1) فك الضغط.
2) ارفع ملف index.html فقط إلى GitHub Repository.
3) من Settings > Pages اختر Deploy from a branch ثم main و /root.
4) افتح الرابط بعد دقيقة.

الدخول الافتراضي:
admin
1234

مهم:
هذه النسخة تعمل بدون Node.js وبدون SQL Server حتى تشتغل على GitHub Pages.
البيانات تحفظ داخل متصفح الجهاز نفسه LocalStorage.
لعمل نسخة احتياطية: التقارير والنسخ > نسخة احتياطية JSON.
لا تعتمد عليها كنظام رسمي متعدد الأجهزة. للنسخة الرسمية استخدم SQL Server على سيرفر داخلي.
