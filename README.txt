نظام متابعة الوجبات - نسخة استضافة مجانية مؤقتة

هذه النسخة مصممة للرفع المباشر على Render / Railway / Koyeb.
لا تحتاج SQL Server ولا Access.
الحفظ يتم داخل ملف: data/db.json

بيانات الدخول الافتراضية:
admin
1234

تشغيل محلي على الحاسبة:
1) افتح CMD داخل مجلد المشروع
2) npm install
3) npm start
4) افتح http://localhost:3000

رفع على Render:
1) ارفع هذا المجلد إلى GitHub كـ Repository.
2) ادخل render.com وسوِ New Web Service.
3) اربط Repository.
4) Runtime: Node
5) Build Command: npm install
6) Start Command: npm start
7) Plan: Free
8) Deploy

ملاحظة مهمة:
هذه نسخة تجربة مجانية. في بعض الاستضافات المجانية، البيانات داخل ملفات السيرفر قد تضيع عند إعادة النشر أو إعادة تشغيل الخدمة.
للاستخدام الرسمي الدائم، استخدم نسخة SQL Server أو قاعدة بيانات خارجية.
